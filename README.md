# Agentia

AI-powered integrated development environment for managing AI agent interactions.

## Development

```bash
# Install dependencies
pnpm install

# Run development server
pnpm tauri dev

# Build application
pnpm tauri build
```

## Tech Stack

- **Frontend**: Svelte 5 + TypeScript + Tailwind CSS
- **Backend**: Tauri (Rust)
- **UI Components**: shadcn-svelte
